# Wisdom Club – Practice Project

A **practice-based static website** focused on wisdom, mindset, and improving the life of modern men.

This project is built mainly for **learning, experimentation, and front-end practice**.

---

## 🎯 Project Goal

The goal of this project is to practice:

- Front-end structure and layout
- UI/UX decisions for content-based websites
- JavaScript logic for simple interactions
- Project organization and GitHub workflow

The content theme revolves around:

- Wisdom & philosophy
- Personal growth
- Mindset and discipline
- Practical ideas for men’s self-improvement

---

## 🧱 Tech Stack

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**

---

## 🔐 Admin Section (Practice Only)

- Simple admin login system implemented with **JavaScript**
- Credentials stored in a local JSON file
- Login state handled using `localStorage`
- Used only to practice logic and UI flow

> ⚠️ This system is **not secure** and is intended purely for learning.

---

## 🎨 Design Notes

- Light theme (white, cream, soft gray)
- Minimal and calm visual style
- Focus on readability and clarity
- Reusable UI components where possible
